# James-developed skills

This directory holds skills developed specifically for James and this Hermes profile.

Use this convention:

- Put James-owned skills under `/opt/data/skills/james/<short-name>/`.
- Keep bundled, hub-installed, or upstream Hermes skills in their existing category paths.
- Keep the frontmatter `name` descriptive and stable. It does not need a `james-` prefix when the path already makes ownership clear.
- Use supporting files under each skill's `references/`, `templates/`, `scripts/`, or `assets/` directories.

Current local skills:

- `writing-standards/`: James's general writing and editing standards.
- `agent-operations/`: James's preferred agent operating habits.
- `rhew-org-standards/`: James's rhew/rhew.org repository conventions.

Checkpoint this directory when preserving local agent behavior.
